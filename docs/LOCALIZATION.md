# Localization

The application shell, authentication, dashboard, and primary invoice-entry actions support English (`en`), Tamil (`ta`), and Hindi (`hi`). The selected language is stored on the device and updates the document language for assistive technology.

GST, GSTIN, HSN/SAC, CGST, SGST, IGST, IRN, and e-way bill identifiers stay in standard English where translating them could make statutory terms ambiguous. Missing translations fall back to English.
